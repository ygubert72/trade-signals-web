# 📊 Торговый сигнальный советник по фьючерсам

Веб-приложение для анализа фьючерсов **RTS** (Индекс РТС) и **Si** (Доллар-рубль) на Московской бирже.

## 🎯 Что делает

- Получает данные с **MOEX API** (бесплатно, без регистрации)
- Рассчитывает индикаторы:
  - **EMA** (50 и 100)
  - **RSI** (14)
  - **ADX** (14)
- Генерирует сигналы: **BUY** / **SELL** / **HOLD**
- Анализирует **паттерны** (10+ классических фигур)
- Работает на таймфреймах: час, день, неделя, месяц

## 🧩 Паттерны

- Пин-бары на экстремумах
- Золотой крест (50/200 MA)
- Касание/пробой 200MA
- Пробой локального уровня
- Двойная вершина / двойное дно
- Голова и плечи
- Чашка с ручкой
- Пробой фрактальной линии (19)
- Ложный пробой уровня
